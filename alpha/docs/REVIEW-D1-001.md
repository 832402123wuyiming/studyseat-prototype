## 已复现并修复的问题

| 编号 | 优先级 | 原行为与影响 | 修复与回归 |
| --- | --- | --- | --- |
| R1 | P2 | CSRF 比较直接接受非 ASCII 字符串，收到如 é 的请求头时触发 TypeError，返回服务器异常 | 比较前拒绝非 ASCII 值，统一返回 403 CSRF_INVALID；1 个回归场景 |
| R2 | P2 | JSON 中孤立代理码点进入密码哈希或 SQLite 时抛编码异常；NUL 文本可能触发表约束或被不一致地保存 | 验证账号、密码与文本为有效 UTF-8 并拒绝 NUL，无效输入返回 400；5 个回归场景 |
| R3 | P2 | 健康接口未判断版本记录查询结果，删除版本记录或改为不支持的版本后仍返回 200 | 同时检查 PRAGMA user_version 与版本记录，异常返回 503 DATABASE_UNAVAILABLE；2 个回归场景 |
| R4 | P2 | 登录在事务提交前修改 Cookie。注入审计失败时数据库回滚，浏览器却收到指向不存在会话的新 Cookie，原登录身份丢失 | 数据库提交成功后才更新 Cookie；数据库错误返回结构化 503。触发器注入审计失败，检查 Cookie、原身份及会话数量保持；1 个回归场景 |

修复前，新增的 9 个回归场景均失败；另单独复核了 R4 的 Cookie 确实被错误替换。修复后这些场景与原有用例一同通过。
